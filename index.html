Capacités, méthode et limites

Capacités réelles : réponses à partir de règles, attribution de « je » et « tu » dans les cas simples, mémoire de faits déclarés, classification supervisée de six intentions, sauvegardes et contrôles.

Méthode : un petit classifieur apprend des associations entre les mots et les catégories. Les poids numériques changent pendant l’entraînement. Les réponses restent des formulations programmées.

Limites : pas de recherche web, d’accès à vos autres applications, de microphone, de compréhension générale des citations ou d’apprentissage continu lorsque l’application est fermée. Un score de classement n’est pas une probabilité de vérité.

L’historique est borné pour préserver les ressources du téléphone. Les compteurs de réduction sont conservés dans l’export.

Gratuité : aucun appel à une API d’IA, aucune publicité, aucun serveur de calcul requis par le programme. L’adresse hébergée dépend des conditions de son hébergeur. Le code complet peut être conservé et réhébergé.
